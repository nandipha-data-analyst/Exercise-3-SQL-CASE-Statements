# Exercise 3: SQL CASE Statements

This repository contains practical solutions for advanced data analysis using **SQL CASE Statements**. The exercises focus on transforming raw datasets by applying conditional logic, data categorization, and flag creation directly within queries.

## Project Overview
Conditional logic is a core skill for any Data Analyst. This project demonstrates how to use `CASE` statements to handle real-world business rules, clean data, and construct structured query outputs. 

* **Platform Used:** Databricks / SQL
* **Core Concepts:** Conditional filtering (`CASE WHEN`), logical operators (`AND`/`OR`), data flagging, and column restructuring.

## Repository Structure
* `Exercise 3.docx`: Contains CASE Statement problems, practice questions, and analytical scenarios with solutions.
